# FUTURE_DS_03 – College Event Feedback Analysis

This project is part of the Future Interns Data Science track, focused on analyzing student feedback from campus events like workshops, tech fests, seminars, and cultural programs. Using Python and basic NLP tools, we turn raw survey data into actionable insights to help organizers improve future events.

# Project Objectives
- Clean and prepare feedback data exported from Google Forms
- Analyze rating-based feedback (1–5 scale) to identify satisfaction trends
- Perform sentiment analysis on student comments using TextBlob
- Visualize insights with charts, heatmaps, and word clouds
- Recommend improvements based on data patterns

##Tools & Technologies
| Tool        | Purpose                        |
|-------------|--------------------------------|
| Google Colab | Online coding (no setup needed) |
| pandas       | Data manipulation              |
| seaborn/matplotlib | Visualization             |
| TextBlob     | Sentiment analysis (NLP)       |

#Key Features
- Rating distribution and average scores per feedback aspect
- Overall satisfaction score calculation
- Sentiment classification (positive, neutral, negative)
- Correlation heatmap to explore relationships between feedback metrics
- Summary dashboard with recommendations

# Repository Contents
- `feedback_analysis.ipynb` – Jupyter Notebook with full analysis
- `student_feedback.csv` – Sample dataset from Google Forms
- `README.md` – Project overview and instructions

#Example Insights
- Top-rated events based on student feedback
- Most common complaints from comments (via word cloud)
- Correlation between ratings and event type (e.g., workshop vs seminar)
- Department-wise satisfaction trends

#How to Use
1. Open `feedback_analysis.ipynb` in Google Colab
2. Upload your CSV dataset from Google Forms
3. Run the notebook step-by-step to clean, analyze, and visualize feedback
4. Review the final charts and recommendations
